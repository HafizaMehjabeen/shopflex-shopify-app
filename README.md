# ShopFlex: Social Icons and Widget App

A Shopify App Store app that lets merchants add and manage social and engagement widgets without writing code.

**Live listing:** https://apps.shopify.com/shopflex-1
**My role:** Shopify App Developer

## What it does

- 250+ icons, custom designs, official brand logos and prebuilt templates
- Responsive controls and visibility settings
- Widget management and analytics tracking in a merchant dashboard

## Stack

Remix, React, JavaScript, theme app extension

Source code is private.
